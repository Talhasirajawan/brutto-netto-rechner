# Brutto-Netto-Rechner (Gross–Net Calculator)

A polished German salary calculator: gross → net for **2025 & 2026**.

- Income tax per **§32a EStG** (exact 2025/2026 tariff coefficients)
- Solidarity surcharge, church tax, tax classes **I–VI**
- Social insurance — pension, unemployment, health, long-term care — incl. **Saxony** split, **child** reductions and the **under-23** care rule
- **Bonus** (one-time payment) and **tax allowance (Freibetrag)**
- Statutory (GKV) or **private (PKV)** insurance
- **DE / EN** languages, **dark / light** mode, live calculation, employer-cost breakdown

## Run locally

Open `index.html` in any browser. No build step or dependencies required.

## Deploy

This repository is configured for **GitHub Pages** (served from the root of the `main` branch).
